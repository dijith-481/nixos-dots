# Manual installs

Programs installed imperatively (not via Nix flake):

- vp (vite-plus)
- agy (antigravity CLI)
- opencode2 (opencode v2 beta)
- codex (Muse)
- hermes (hermes-agent)
- commandcode (command-code)

Note: `programs.nix-ld.enable = true` is set in `hosts/celestia/configuration.nix` for dynamically linked binaries.
